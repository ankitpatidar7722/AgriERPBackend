# AgriERP — PostgreSQL schema scripts

Hand-written PostgreSQL parallel of `database/scripts/` (which stays the SQL Server
source of truth). These produce the **final** schema state directly — the SQL Server
side reached it through incremental/restructure scripts; there is no reason to replay
that history on a fresh database.

Run order mirrors the SQL Server numbering (dependency order). Create the database
first, then run the numbered files in order:

```
psql -U postgres -c "CREATE DATABASE agrierp"
psql -U postgres -d agrierp -f 02_security.sql
psql -U postgres -d agrierp -f 03_masters.sql
...
```

To re-run from scratch during development:

```
psql -U postgres -d agrierp -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"
```

## Translation conventions (T-SQL → PostgreSQL)

| SQL Server | PostgreSQL |
|---|---|
| `[dbo].[Name]`, unquoted `Name` | `"Name"` — **always double-quoted** so the case matches what EF/Npgsql emit |
| `NVARCHAR(n)` / `NCHAR(n)` | `varchar(n)` / `char(n)` |
| `INT` / `BIGINT` / `TINYINT` | `int` / `bigint` / `smallint` |
| `BIT` (`DEFAULT (0)` / `(1)`) | `boolean` (`DEFAULT false` / `true`) |
| `DATETIME2(3)` | `timestamp(3)` |
| `DATE` / `TIME(0)` | `date` / `time(0)` |
| `DECIMAL(p,s)` / `MONEY` | `numeric(p,s)` / `numeric(19,4)` |
| `UNIQUEIDENTIFIER` / `NEWID()` | `uuid` / `gen_random_uuid()` (built-in, PG 13+) |
| `VARBINARY(n)` | `bytea` |
| `ROWVERSION` column | **dropped** — Npgsql uses the system `xmin` column for concurrency (see EF `HasRowVersionConcurrency`) |
| `IDENTITY(1,1)` | `GENERATED BY DEFAULT AS IDENTITY` (matches Npgsql's default strategy) |
| `col AS (expr) PERSISTED` | `col <type> GENERATED ALWAYS AS (expr) STORED` (PG needs the explicit type) |
| `SYSUTCDATETIME()` | `(now() at time zone 'utc')` |
| `ISNULL(a,b)` | `COALESCE(a,b)` |
| `CONVERT(decimal(18,2), x)` | `CAST(x AS numeric(18,2))` |
| `N'text'` | `'text'` |
| `PRIMARY KEY CLUSTERED` | `PRIMARY KEY` (no clustered concept in PG DDL) |
| filtered index `... WHERE IsDeleted = 0` | partial index `... WHERE "IsDeleted" = false` |
| `CREATE INDEX ... INCLUDE (...)` | same — `INCLUDE` supported (PG 11+) |
